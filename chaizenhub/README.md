# Chaizenhub

Situs statis (HTML/CSS/JS), siap deploy ke Vercel.

## Deploy
1. Extract zip ini.
2. Upload folder ke GitHub lalu Import di vercel.com/new, ATAU jalankan `npx vercel` di folder ini.
3. Framework preset: **Other**. Build command & output dir: kosongkan.

Catatan: Tailwind dimuat via CDN (cdn.tailwindcss.com).
